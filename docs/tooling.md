# مرجع الأدوات

هذا فهرس إرشادي؛ لا يعني أن كل أداة مثبتة أو مطلوبة في كل مشروع. تحقق من النشاط والترخيص والتوافق قبل تثبيت أي مهارة أو سكربت من مستودع خارجي.

## مراجع المنصات
- FastAPI: https://fastapi.tiangolo.com/ — عند استخدامه لبناء API.
- Supabase: https://supabase.com/docs — عند استخدام خدمات Supabase فعلاً.
- Cloudflare Workers AI: https://developers.cloudflare.com/workers-ai/
- Cloudflare Workers: https://developers.cloudflare.com/workers/
- Cloudflare Secrets: https://developers.cloudflare.com/workers/configuration/secrets/
- GitHub REST API: https://docs.github.com/rest

## مستودعات مهارات محتملة
- https://github.com/DietrichGebert/ponytail — قد يساعد في تقليل التعقيد؛ راجع المحتوى قبل اعتماد قواعده.
- https://github.com/cloudflare/security-audit-skill — مرجع محتمل لمراجعة الأمان؛ تحقق من تعليمات التثبيت والتوافق.
- https://github.com/Graphify-Labs/graphify — قد يفيد في فهم مستودعات كبيرة، وليس ضرورياً لكل مشروع.
- https://github.com/fastapi/fastapi وhttps://github.com/supabase/supabase — مراجع تقنية للمشاريع التي تستخدم هذه الأدوات وليست مهارات عامة.

تعليمات Claude Code لا تعمل بالضرورة مباشرة مع أي وكيل آخر. تكيّفها مع بيئة التنفيذ، وراجعها قبل منحها صلاحية استدعاء الأدوات.
