# قواعد البرمجة

- اقرأ البنية وإصدارات اللغة والأطر والاختبارات قبل الكتابة.
- اتبع نمط المشروع القائم، ونفّذ أصغر تغيير واضح يحقق المطلوب.
- فضّل المكتبات الحالية والأدوات القياسية؛ لا تضف framework أو dependency لمجرد التفضيل.
- استخدم أسماء واضحة ودوال ذات مسؤولية محددة، دون تجريد مبالغ فيه.
- تحقق من النوع والطول والنطاق والقيم الفارغة عند حدود النظام.
- استخدم معاملات SQL المعلّمة، وافصل البيانات عن أوامر shell.
- لا تبتلع الاستثناءات ولا تترك placeholders في مسار يفترض أنه مكتمل.
- حافظ على توافق API؛ وثّق التغييرات الكاسرة وخطة ترحيل البيانات.
- لا تغيّر تنسيق أو أسماء ملفات غير مرتبطة بالمهمة.
- اختبر حالات النجاح والفشل والحالات الطرفية والصلاحيات حيث تنطبق.
- راجع diff النهائي بحثاً عن تغييرات غير مقصودة وأسرار وتبعيات غير لازمة.
- إذا نقصت معلومة تؤثر في الأمان أو البيانات أو التوافق، اسأل بدلاً من التخمين.
